Do not place seed phrases, private keys, or wallet export files in this repository or the smoke notes. Keep transaction identifiers and public addresses as the evidence.

UniSat [lists Bitcoin Testnet and Bitcoin Testnet4 as separate chains](https://docs.unisat.io/developer-support/open-api-documentation/unisat-wallet/supported-chains), both with the `tBTC` unit. Its [mobile transfer instructions](https://docs.unisat.io/products/unisat-wallet/how-to-deposit-withdraw-assets) describe signing and sending with no raw-hex export step. Its separate [mobile developer interface](https://docs.unisat.io/developer-support/open-api-documentation/unisat-wallet/connect-with-unisat-mobile-wallet) documents a `signPsbt` deeplink and a response deeplink, while the [wallet API](https://docs.unisat.io/developer-support/open-api-documentation/unisat-wallet) specifies that `signPsbt` returns signed **PSBT hex**, not raw transaction hex. A compatible helper is an implementation path, not a completed or device-tested workflow. Keep this wallet on Bitcoin Testnet; do not transfer the recovery phrase into another tool to satisfy the gate.

The A2 path is a separate [Sparrow desktop wallet](https://sparrowwallet.com/download/) with `testnet4` selected. [Sparrow's configuration](https://github.com/sparrowwallet/sparrow#configuration) distinguishes `testnet4` from legacy `testnet` (Testnet3); its [feature guide](https://sparrowwallet.com/features/) says a final signed transaction can be saved or copied from the hex view. [Bitcoin Core](https://github.com/bitcoin/bitcoin/blob/master/src/chainparamsbase.cpp) marks Testnet3 deprecated and recommends Testnet4. Generate and back up the wallet in Sparrow, never in ChainPay or this repository. The separately funded wallet leaves the existing UniSat UTXO and recovery phrase untouched.

The Sparrow address was first checked against Testnet3 at 2026-10-26 02:06 UTC and correctly showed zero there; the wallet was actually on Testnet4. At 2026-10-26 14:28 local time, a packaged ChainPay 44.4.5 watch on Testnet4 displayed the unconfirmed 50,000-sat faucet payment, one UTXO, and the matching transaction. See the [live evidence](phase-5-slice-a-bitcoin-watch-live-2026-10-26.md). The app's direct Node request timed out in this test environment, so the packaged smoke used a temporary localhost relay to the public Testnet4 Esplora API; provider routing and data parsing were exercised, while direct Node connectivity remains an environment check.
